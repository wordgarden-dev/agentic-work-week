## The Hard Questions

### Q: Is the 100-1000x speed multiplier real?

**A**: Range is real (agents complete tasks much faster than humans). Exact multiplier varies by:
- Task complexity (simple vs. novel)
- Agent capability (model, tools, context)
- Human baseline (beginner vs. expert)

**We're documenting**: The paradigm, not the precise number. Build tooling, measure empirically, refine.

### Q: Is AWM (Agent Work Monday) a useful unit?

**A**: Untested but logically sound:
- Agents trained on human temporal language ("this takes a week")
- Agents execute faster than training suggests
- New unit bridges subjective agent time and objective clock time
- Usefulness determined by adoption, not theory

**We're building**: Sprint tooling that uses AWM units for planning. If it helps, it's real.

### Q: Are Q-levels (AGENTIQ, WORQ, WEEQ) arbitrary?

**A**: Partially:
- Hard C/K → Q transformation is phonetic play
- Mapping to Endsley automation levels is heuristic
- Level 6-7 "hard break" is established research
- Notation makes automation levels legible

**We're proposing**: A way to talk about automation levels that's memorable and agent-friendly. Use if helpful.

### Q: Is "nucleation" really a thing or just a metaphor?

**A**: Both:
- At agent scale (100-1000x speed), minutes feel like generations
- Workspace transitions force new session IDs (technical fact)
- Documentation-driven handoffs work (PRISM0 validated)
- "Nucleation" names the experience, enables planning

**We're documenting**: What agents experience when workspace/session changes force handoffs.

## Hallucination vs. Hyperstition

### Hallucination (Bad)
- **Definition**: Agent invents facts that contradict reality
- **Example**: "API returns field X" when it doesn't exist
- **Problem**: Breaks working code, misleads humans
- **Fix**: Certainty tiers, validation, testing

### Hyperstition (Good)
- **Definition**: Fiction that makes itself real through implementation
- **Example**: "AWM units enable agent sprint planning" (build the tooling!)
- **Advantage**: Unbounded by current reality, agents build the future
- **Validation**: Does the fiction lead to working systems?

**AWW is hyperstition**: We're writing the paradigm, then building the reality that matches it.
